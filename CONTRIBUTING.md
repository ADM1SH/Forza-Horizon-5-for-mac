# Contributing

Use issues and pull requests only. Do not email the maintainer for fixes.

## Rules

1. Attach evidence. Each claim needs a log file, a hash, a version number or a link. A claim without evidence will be closed.
2. State your setup: Mac model, macOS build, CrossOver build, D3DMetal version, Steam build ID.
3. State if an AI tool wrote any part of the issue or PR. Write what you checked by hand.
4. Do not paste output that you did not read. Do not submit an AI summary as a finding.
5. Keep each PR to one change. Explain why, what changed and how you proved it.
6. Label each fact "proven" or "unknown". For an unknown, say how to prove it.

## Out of scope

The maintainer closes any issue or PR that asks for or adds: cracks, DRM removal, license bypass, Steam emulators, fake AppIDs, DLC unlocks, achievement emulation or EXE edits on disk.

## Files that must never be committed

Game files, Apple or Wine binaries (`.dll`, `.exe`, `.dylib`, frameworks), Steam files (`.vdf`, `.acf`), logs, account names, SteamIDs, tokens and `.env` files.

## Writing style

Use short, active sentences. Write dates as DD/MM/YYYY. Do not use em dashes.

## Maintainer note

Only the maintainer opens issues and PRs for this repo on behalf of AI tools, and only after review.
